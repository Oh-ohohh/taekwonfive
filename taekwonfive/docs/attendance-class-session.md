# 출석 수업 부

출석 체크 시 한국 시간(Asia/Seoul)으로 수업 부를 자동 지정합니다. 하루에 학생당 하나의 부를 저장합니다.

| 부 | 수업 시간 | 자동 지정 시간 |
|---|---|---|
| 1부 | 14:00~14:50 | 13:50~14:50 |
| 2부 | 15:30~16:20 | 15:20~16:20 |
| 3부 | 17:00~17:50 | 16:50~17:50 |
| 4부 | 18:30~19:20 | 18:20~19:19 |
| 5부 | 19:30~20:20 | 19:20~20:19 |
| 6부 | 20:30~22:00 | 20:20~22:00 |

시각은 분 단위로 판정합니다. 종료 분도 포함하며, 19:20부터는 5부, 20:20부터는 6부가 우선합니다. 시간 공백과 과거 날짜의 출석은 자동 지정하지 않습니다.

출석된 학생의 이름 옆 선택 메뉴에서 1~6부로 수정하거나 `부 선택`으로 해제할 수 있습니다. 부 수정은 출석 상태, 원래 체크 시각, 메모를 바꾸지 않습니다. 저장 실패 시 기존 값을 유지합니다. 출석 자체를 해제하면 해당 날짜의 기록과 부가 함께 삭제되며, 다시 출석하면 체크 시각에 따라 새로 지정합니다.

`attendance_records.class_session`에 1~6 또는 null을 저장합니다. 기존 기록은 null로 유지하여 체크 시각만으로 부를 추정하지 않습니다. 새 환경에서는 앱 사용 전에 마이그레이션을 적용합니다.

```powershell
node --env-file=.env.local scripts/manage-class-session.mjs inspect
node --env-file=.env.local scripts/manage-class-session.mjs apply
```

관리 자격 증명은 기존 관리자 스크립트와 동일하게 환경 변수 또는 `.mcp.json`에서 읽고 출력하지 않습니다. 이미 열이 있으면 다시 추가하지 않고 타입과 제약 조건을 검사합니다.

검증:

```powershell
node scripts/verify-class-session.mjs
npm run lint
npm run build
```

검증 스크립트는 시간대별 경계값, 과거 날짜, 서비스의 자동 지정·수정·재조회·실패·출석 해제와 재체크, 선택 메뉴 구조를 검사합니다. 서비스 저장 검증에는 데이터베이스 대역을 사용합니다.
