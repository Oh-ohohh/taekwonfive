# 출석 요일과 휴관

`students.attendance_days`의 ISO 요일 번호를 사용합니다. 월요일은 1, 일요일은 7입니다. 월~금은 `[1,2,3,4,5]`이며, null 또는 빈 배열은 휴관으로 취급합니다. 저장할 때 빈 배열은 null로 바꿉니다.

- 오늘의 기본 명단은 해당 요일의 수업 대상과 이미 체크한 추가 출석 학생입니다.
- 전체 학생에서 다른 요일의 재원 학생을 보강 출석시킬 수 있습니다. 추가 출석을 해제하면 기본 명단에서 다시 제외됩니다.
- 휴관 학생은 전체 학생에서 휴관으로 표시하며, 새로운 출석 체크는 막습니다. 수련생 관리에서 요일을 지정하고 저장하면 복귀합니다.
- 현재 휴관 중이어도 이미 저장된 출석 기록은 표시하며, 부 수정과 출석 해제가 가능합니다.
- 대상 중 출석, 체크 전, 결석 및 출석률은 해당 요일의 대상 학생만 집계합니다. 전체 출석에는 추가 출석도 포함합니다. 당일에는 체크 전을 결석으로 바꾸지 않습니다.
- 다음 날이 되면(앱을 열거나 화면으로 돌아올 때) 어제까지 체크하지 않은 수업 대상 학생을 결석으로 저장합니다. 이미 기록이 있는 학생, 공휴일·주말, 다른 요일, 휴관, 그날 이후 등록한 학생은 제외합니다. `AUTO_ABSENT_START_DATE`(2026-10-08) 이전과 31일보다 오래된 날짜는 소급하지 않습니다.
- 출석 카드의 부 드롭다운은 1~6부 다음에 결석, 기타 순서입니다. 결석·기타에는 선택 메모를 남길 수 있습니다. 기타는 출석도 결석도 아니며 따로 집계합니다(PDF에서는 △). DB의 status 제약을 바꾸지 않도록 기타는 `status = 'absent'`와 note 앞의 `[기타]` 표식으로 저장하고, `attendance-service.ts`에서만 변환합니다.
- 공휴일(`src/lib/holidays.ts`, 대체공휴일 포함)과 토·일요일은 휴일로 표시하며 수업 대상이 없습니다. 출석 체크가 필요 없지만, 나온 학생은 전체 학생에서 휴일 출석으로 추가할 수 있습니다. 공휴일 목록은 2027년까지 들어 있으므로 해마다 다음 해 날짜를 추가해야 합니다.
- 수업 대상이 없으면 출석률은 계산하지 않습니다.
- 과거 날짜의 기본 명단은 저장된 출결 기록입니다. 일정 이력이 없으므로 현재 요일 설정으로 과거 대상 인원이나 출석률을 추정하지 않습니다. 과거 날짜의 전체 학생 화면에서는 누락된 출석을 입력할 수 있습니다.
- 데이터베이스의 숫자 학생 ID는 서비스에서 문자열로 변환하여 기존 화면과 출석 데이터의 ID 표현을 통일합니다.

검증:

```powershell
node scripts/verify-attendance-roster.mjs
node scripts/verify-class-session.mjs
npm run lint
npm run build
```

요일·시간대, 휴관/복귀, 추가 출석, 과거 기록, 집계 및 서비스 저장 동작을 확인합니다. 저장 동작 검증은 실제 학생 정보를 바꾸지 않는 데이터베이스 대역을 사용합니다.
